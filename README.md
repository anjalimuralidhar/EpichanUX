# EpichanUX

A lightweight team project & task management web app. EpichanUX gives small teams a
single place to track projects, assign tasks, and stay on top of notifications.

Built with **React + TypeScript + Vite**.

## Features

- **Dashboard** — at-a-glance stats on active projects, health, and open tasks
- **Projects** — a sortable table of workstreams with owners, status, and progress
- **Settings** — account and notification preferences with toggle controls

## Getting started

```bash
npm install
npm run dev
```

Then open the URL Vite prints (default http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Project structure

```
src/
  components/     Shared UI: Sidebar, TopBar, Toggle, SettingsRow
  pages/          Dashboard, Projects, Settings
  data/           Sample project data
```
